Step-by-Step Setup

Detailed instructions for each step.

1. Install VM Studio

Open Figma, visit VM Studio on Figma Community, click "Open in..." and select your workspace.

2. Get Your API Key

fal.ai (Recommended): Go to fal.ai/dashboard/keys, sign up or log in, create new key, copy it.

OpenAI: Go to platform.openai.com/api-keys, create secret key, copy immediately.

Google AI Studio: Go to aistudio.google.com/apikey, sign in, create API key, copy it.

3. Configure Plugin

Open any Figma file, go to Plugins menu → VM Studio, click Settings (gear icon), paste API key, close.

Your key is stored locally. Never sent to VM Studio servers.

4. Generate First Image

Select model from dropdown, type a prompt, press Cmd+Enter, image appears on canvas.

Troubleshooting

Common issues and fixes.

"Invalid API key"

Delete current key, paste fresh one. Check for extra spaces.

"Rate limit exceeded"

Wait a few minutes. Check provider dashboard.

Images not appearing

Press Cmd+1 to zoom to fit. Look for new nodes.
