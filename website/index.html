Frequently Asked Questions

What AI models does VM Studio support?

VM Studio supports 5 AI models: Nano Banana Pro, Z-Image Turbo, Seedream v4, FLUX.2 Turbo, and GPT-Image 1.5. Each model has unique strengths for different creative needs.

Do I need to pay for VM Studio?

The plugin is free to install. VM Studio uses a BYOK (Bring Your Own Key) model. You use your own API keys from providers like fal.ai, OpenAI, Google AI Studio, or OpenRouter and pay directly to them based on usage.

What is the maximum resolution for generated images?

VM Studio supports image generation up to 4K resolution, depending on the AI model selected. You can choose between 1K, 2K, and 4K outputs.

Can I generate multiple images at once?

Yes, VM Studio supports batch image generation, allowing you to create multiple image variations simultaneously with smart grid placement on your Figma canvas.

Does it support image-to-image generation?

Yes, you can select existing images in Figma and use them as a reference for AI-powered transformations, style transfers, and refinements.
