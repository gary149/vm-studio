## Step-by-Step Setup

### 1. Install VM Studio
- Open Figma
- Visit VM Studio on Figma Community
- Click "Open in..." → select workspace

### 2. Get Your API Key

**fal.ai (Recommended)**
1. Go to fal.ai/dashboard/keys
2. Sign up or log in
3. Create new key → Copy

**OpenAI**
1. Go to platform.openai.com/api-keys
2. Create secret key → Copy immediately

**Google AI Studio**
1. Go to aistudio.google.com/apikey
2. Sign in → Create API key → Copy

### 3. Configure Plugin
1. Open any Figma file
2. Plugins menu → VM Studio
3. Click Settings (gear icon)
4. Paste API key → Close

Your key is stored locally. Never sent to VM Studio servers.

### 4. Generate First Image
1. Select model from dropdown
2. Type a prompt
3. Press Cmd+Enter
4. Image appears on canvas

## Troubleshooting

**"Invalid API key"**
Delete current key, paste fresh one. Check for extra spaces.

**"Rate limit exceeded"**
Wait a few minutes. Check provider dashboard.

**Images not appearing**
Press Cmd+1 to zoom to fit. Look for new nodes.
