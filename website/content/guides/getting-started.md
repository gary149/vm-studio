## Step-by-Step Setup Guide

### Step 1: Install VM Studio from Figma Community
1. Open Figma (desktop app or browser)
2. Visit the VM Studio plugin page on Figma Community
3. Click **"Open in..."** and select your workspace
4. The plugin is now installed

### Step 2: Get Your API Key

**Option A: fal.ai (Recommended)**
1. Go to fal.ai/dashboard/keys
2. Sign up or log in
3. Click **"Create new key"**
4. Copy your API key

**Option B: OpenAI**
1. Go to platform.openai.com/api-keys
2. Sign up or log in
3. Click **"Create new secret key"**
4. Copy the key immediately

**Option C: Google AI Studio**
1. Go to aistudio.google.com/apikey
2. Sign in with Google
3. Click **"Create API key"**
4. Copy your API key

**Option D: OpenRouter**
1. Go to openrouter.ai/keys
2. Sign up or log in
3. Click **"Create Key"**
4. Copy your API key

### Step 3: Configure Your API Key
1. Open any Figma file
2. Launch VM Studio: **Menu > Plugins > VM Studio**
3. Click the **Settings** icon (gear icon)
4. Paste your API key in the appropriate field
5. Close settings - your key is saved automatically

Your API key is stored locally on your device. It's never sent to VM Studio's servers.

### Step 4: Generate Your First Image
1. Select a model from the dropdown
2. Type a prompt describing the image you want
3. Click **Generate** or press `Cmd + Enter`
4. Watch as your image appears on the canvas

## Troubleshooting Common Issues

### "Invalid API key" Error
Go to Settings, delete the current key, paste a fresh one. Check for extra spaces.

### "Rate limit exceeded" Error
Wait a few minutes and try again, or check your provider's dashboard.

### "Model not available" Error
Check which provider supports your chosen model.

### Images Not Appearing
Use `Cmd + 1` to zoom to fit and look for newly created nodes.

### Plugin Not Loading
Close Figma completely and reopen. Reinstall if needed.

## FAQ Section

### How much does it cost?
VM Studio is free. You pay API providers directly. Most images cost $0.01-0.05. Google AI Studio offers a free tier.

### Can I use multiple providers?
Yes. Add API keys for all four providers and switch between them.

### Are my generated images private?
Your images go directly from the provider to your Figma canvas. VM Studio doesn't see or store them.

### Do I need a paid Figma account?
No. VM Studio works with free Figma accounts.
